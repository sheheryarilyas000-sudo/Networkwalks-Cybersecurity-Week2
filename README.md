Cybersecurity Internship - Week 2 Project 🚀

🔐 Project Overview

This repository contains my Week 2 project for the Cybersecurity Internship Program at Networkwalks (Batch B084). The primary focus of this week was on Information Gathering (Footprinting), Reconnaissance, and Network Discovery phases using Kali Linux.

🎯 Objectives

Conduct passive footprinting against a target domain (networkwalks.com).

Enumerate web technologies, HTTP headers, WAF presence, and DNS records.

Perform internal network scanning and host discovery on a local virtual NAT network.

Generate a visual network topology.

Document all technical findings and risk analyses in a professional Penetration Testing Report.

🛠️ Tools Used

Kali Linux (Attacker Machine)

WHOIS: Domain registration details.

WhatWeb: Web technology fingerprinting.

Nslookup: DNS to IP resolution.

Curl: HTTP response header inspection.

Wafw00f: Web Application Firewall (WAF) detection.

DNSRecon: DNS records enumeration (SOA, NS, MX, TXT, SRV).

Zenmap (Nmap GUI): Subnet scanning (Ping scan) and Topology generation.
